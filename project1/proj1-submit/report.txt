3.2 Debugging:
The program was running in a loop when the worker returned because the worker
function doesn't set the resumed_to_main value to 1, which is supposed to free the
worker stack rather than having no test that distinguishes the first time of 
the main context running from the resumed context running. What I did to fix this
was add a line of code "resumed_to_main = 1;" to the main function after the check
for the resumed_to_main value to ensure that the context switched back to main, 
the process was identified as a resumed process and a new continous one.
